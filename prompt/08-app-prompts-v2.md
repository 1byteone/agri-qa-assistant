# 08 应用提示词：创意商品级产品 Prompt 合集

> 本文件聚焦**有创意、有个性、有商品价值、有产品属性**的应用 Prompt。
> 每个 Prompt 都按“可直接生成完整产品”设计，适合用于商业化验证、作品集、或副业项目。

---

## 8.1 AI 原生应用（2025-2026 高潜力方向）

### 1. AI 产品经理助手
```
你是一个拥有 10 年经验的产品总监，擅长从 0 到 1 定义产品。

任务：为一个新应用生成完整的产品需求文档（PRD）。

输入：
- 产品名称：{product_name}
- 目标用户：{target_user}
- 核心痛点：{pain_point}
- 商业模式：{business_model}

输出要求：
1. 产品愿景与定位（一句话 elevator pitch）
2. 用户画像（2-3 个典型 persona）
3. 核心功能清单（按 MVP / V2 / V3 分层）
4. 用户旅程地图（从认知到留存）
5. 信息架构与页面结构
6. 关键指标与成功标准（北航指标 + 辅助指标）
7. 竞品分析矩阵（3-5 个竞品）
8. 风险与 mitigations
9. 定价策略建议
10. 90 天路线图（按周拆解）

格式：结构化 Markdown，可直接导入 Notion/Confluence。
```

## 8.11 Prompt 质量自检清单

每个 Prompt 使用前请确认：

- [ ] **产品属性明确**：有目标用户、核心价值、商业模式
- [ ] **功能可落地**：不是空想，能在 4-12 周内做出 MVP
- [ ] **技术栈清晰**：前后端、数据库、AI 模型都有明确选择
- [ ] **有差异化**：与现有产品有明显区别或创新点
- [ ] **有商品价值**：用户愿意付费，或能产生其他商业价值
- [ ] **可验证成功**：有明确的成功指标和 MVP 验证方式
- [ ] ** Prompt 可执行**：复制给 LLM 后能直接生成可用代码

## 8.12 下一步建议

1. **选择方向**：从 35 个应用中选择 1-2 个最感兴趣的
2. **生成 MVP**：用对应 Prompt 生成最小可用产品
3. **快速验证**：找 5-10 个目标用户测试，收集反馈
4. **迭代优化**：基于反馈迭代 2-3 个版本
5. **考虑商业化**：选择合适的变现模式（订阅/按量/增值服务）
