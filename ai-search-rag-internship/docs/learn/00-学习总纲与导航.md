# 00 学习总纲与导航：传习教育 AI Search/RAG 实习体系

> 本系列把"江西传习教育科技有限公司"实习经历拆成 **2 条产品线 × 4 个能力域** 的可演示、可追问、可解释学习链路。每一册都以真实企业案例/用户故事开头，用案例驱动学习技术，用实验复现简历数字，用面试叙事讲清因果。**干中学，学中用。**

设计文档：`docs/superpowers/specs/2026-08-16-learning-docs-design.md`

## 一、专业 Goal

面向传习教育（教育科技）真实业务场景，在 8 周内完成一个双产品线 AI Search/RAG 项目作品集。最终你要能把每条简历素材讲成闭环：

```text
业务问题 -> 数据样本 -> baseline -> 技术方案 -> 实验参数 -> 指标变化 -> 失败样本 -> 下一步
```

判断标准：**简历里每个数字，都能在本仓库固定评测集上复现，并绑定数据集、模型版本、硬件和参数。**

## 二、传习教育场景总览

### 2.1 两条产品线


## 五、推荐学习顺序

与 `docs/zero-to-one-roadmap.md`（零基础细分教程）的关系：roadmap 是从 0 到 1 的代码跟随路线；本系列是"简历能力域 × 面试深挖"的体系视角。建议：

```text
零基础：先走 zero-to-one-roadmap 的细分 Notebook（01→13）
→ 有实验基础后：按本系列 01→09 顺序，每册先读"企业案例"和"简历映射"，
```

## 八、工作约定（沿用 evidence-first）

- 每个实验保留 baseline，每次只改一个主变量。
- 所有性能/效果数字必须绑定：数据集、模型版本、硬件、参数、命令。
- 简历数字只能以本项目固定评测集上的复现结果为准。
- 失败实验也记录原因。
- 化名规则：公司=传习教育（教育科技）；产品=传习智学/传习智答；人物=角色表。
