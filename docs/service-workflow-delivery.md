# CropWise 服务入口交付说明

## 目标

将作物诊断、农时查询、政策咨询从跳转到通用问答的静态入口，升级为在服务页内完成“结构化采集 -> 受约束检索生成 -> 来源与风险提示”的工作流。当前不引入本地模型，继续使用现有远程模型、FastAPI 与 AgriIR 证据链路。

## 一期范围

| 服务 | 必填采集 | 结果要求 | 风险边界 |
| --- | --- | --- | --- |
| 作物诊断 | 作物、地区、生育期、症状 | 鉴别方向、排查动作、复查节点 | 文字/图片不作确诊；不输出未经核验的农药剂量或混配结论 |
| 农时查询 | 作物、地区、当前环节、农事目标 | 时间窗口、顺序安排、天气风险、替代方案 | 公共预报仅作参考；灾害预警以气象部门为准 |
| 政策咨询 | 地区、主题、主体、年份 | 已核验信息、待核验项、官方办理入口 | 无 A 级官方证据不确认资格、金额、截止日期或办理结论 |

## 交付标准

1. 三个页面均可独立提交表单，并向 `/api/chat` 传入完整场景上下文。
2. 请求过程中有可见的加载状态，失败时显示可理解的错误信息。
3. 成功结果显示模型返回内容、完成状态和可跳转的来源链接；无来源时明确告知用户仍需核验。
4. 政策、农药、肥料等高风险内容仍由后端 AgriIR A 级证据闸门拦截，前端不得绕过该链路。
5. 前端类型检查通过；与运行中的 FastAPI `/chat` 契约兼容。

## 证据资料基线与覆盖判断

下列资料已作为版本化证据包纳入当前检索链路。它们比无发布日期、无发布主体的网页摘要更适合作为一期服务的可追溯基线。

| 资料 | 发布主体 | 服务用途 | 当前结论 |
| --- | --- | --- | --- |
| [农药管理条例](https://fgs.moa.gov.cn/flfg/202312/t20231205_6442161.htm)（2023-12-05） | 农业农村部 | 作物诊断的农药合规边界 | 已入库，A 级；不用于替代具体作物的登记标签 |
| [当前水稻应对高温热害技术意见](https://www.moa.gov.cn/xw/zxfb/202608/t20260805_6486484.htm)（2026-08-05） | 农业农村部 | 水稻农时与天气风险 | 已入库，A 级；覆盖高温应对，不等于县域农时历 |
| [油菜花期用药答记者问](https://www.moa.gov.cn/gk/zcjd/202603/t20260317_6482369.htm)（2026-03-17） | 农业农村部全国农技推广中心、科技发展中心 | 油菜诊断和规范用药提醒 | 已入库，A 级；可支持登记与标签核验提醒 |
| [脐橙冻害风险预警（2026第一期）](https://www.ganzhou.gov.cn/zfxxgk/nyncyjgl/202601/a396bc2c643f4cfc9352b916c1127f4e.shtml)（2026-01-20） | 赣州市政府 | 赣南脐橙天气风险 | 已入库，A 级；是区域预警样例，具有明确时效 |

当前最大缺口是 `jiangxi-rice` 与 `jiangxi-policy` 两个证据包仍只有契约而没有物化材料。因此政策页面在缺少匹配 A 级证据时应保持“待核验”而非输出资格或补贴结论；农时页面也不得把省级或全国技术意见外推为县级固定日期。

## 研究与迭代路径

1. 为江西各设区市建立按作物、发布日期、有效期和证据范围索引的政策清单，并在过期前触发复核。
2. 从省/市气象部门和农技推广体系引入正式预警、农时历和作物病虫情报，分别标注为实时预警、季节历和技术意见，不能互相替代。
3. 诊断页接入图像采集后，保留图像质量门槛、人工复核与样本留痕，不将视觉模型置信度展示为确诊概率。

## 下一阶段待对齐

1. 作物诊断是否需要图片上传、病斑标注和专家工单流转；这决定是否建设对象存储和人工复核队列。
2. 农时数据的权威粒度是省级、县级还是乡镇级；县域以下计划需要接入当地农技历和气象预警源。
3. 政策服务是否只覆盖江西，及是否需要接入政务事项库；这决定证据包扩展与有效期更新机制。
