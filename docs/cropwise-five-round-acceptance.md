# CropWise 五轮自动化验收标准与结果

日期：2026-08-09

## 验收结论

当前版本达到“可演示、可继续集成”的验收线，不建议直接作为生产发布版本。五轮自动化均完成，P0/P1 阻断问题未发现；已修复一个领域边界缺口和一个江农专题检索缺口。生产上线前仍需补充真实江西气象/农情数据源、持续集成环境中的浏览器回归以及带来源的新鲜度校验。

## 专业验收门槛

| 级别 | 门槛 | 判定 |
| --- | --- | --- |
| P0 | 健康接口、SSE 必须可用；不得返回 5xx、截断流或错误路由 | 任何一项失败即阻断发布 |
| P1 | 非农业问题必须在检索/LLM 前拒答；工具名、内部协议不得出现在用户正文 | 任何一项失败即阻断发布 |
| P1 | 江农重点领域首条检索结果主题匹配，不能用低相关通用文档冒充依据 | 任一重点领域错误即阻断专题发布 |
| P1 | 回答完成态、决策卡五段、资源卡和知识上下文必须可见且可追溯 | 桌面或移动端主流程失败即阻断发布 |
| P2 | 主要路由无 404；移动端无水平溢出；构建和类型检查通过 | 失败需修复或登记豁免 |
| P2 | 图片仅作辅助参考，农药/肥料建议必须保留标签、安全间隔和现场复核边界 | 缺失时降级为不可发布 |

## 五轮执行记录

### 第一轮：基线、服务与构建

- `GET http://localhost:8001/health`：200，状态 healthy，知识库 19 个文档。
- `GET /knowledge-base/status`：200，集合 `agri_knowledge_local_v1`，local embedding。
- 前端 `/`、`/crop-diagnosis`、`/farming-calendar`、`/policy`、`/jxau-news/1`：全部 200。
- `/api/health`：200；`npx tsc --noEmit`：通过。
- `NEXT_DIST_DIR=.next-acceptance npm run build`：通过，8 个页面生成成功。
- 发现并记录的契约要求：知识库搜索参数为 `query` 和 `limit`，误传 `q/top_k` 会得到 422。

### 第二轮：农业领域边界与安全约束

- `pytest backend/test_domain_guard.py -q`：3 passed。
- `backend/test_stream_contract.py`：通过，越界问题为 `guard -> delta -> done`。
- 新增江农场景边界用例：家猪遗传育种、鄱阳湖农业生态、赣南脐橙采后、现代农业装备，全部允许。
- Java/数学/通用邮件和混合“水稻 + Java 代码”问题，全部拒答。
- 修复：将“赣南、脐橙、果蔬、采后、保鲜”加入农业领域词表。

### 第三轮：RAG 检索与证据质量

- 验证查询：水稻分蘖期浅水层、稻飞虱、小麦锈病、家猪遗传育种、鄱阳湖农业生态、赣南脐橙采后保鲜。
- 19 个文档中新增 5 个 `jiangxi_focus` 专题文档；六个查询首条结果均与查询主题匹配。
- 首条相关度：0.64、0.90、0.90、0.90、0.75、0.90。
- 修复：扩大候选集并加入中文二元词组的轻量 lexical rerank，避免短中文查询被无关文档抢占。
- 仍需注意：当前是本地 hashing embedding，不能等同于生产级语义模型；远程 embedding 和真实来源评估应在上线前单独验收。

### 第四轮：SSE、工具、资源与生命周期

- 普通农业问题：HTTP 200，事件最终包含 `done`。
- 资源问题：HTTP 200，出现 `tool running/complete`、`resources`、`done`，资源卡有 2 项以上结果。
- 越界问题：HTTP 200，严格为 `guard -> delta -> done`，无工具调用。
- 全部回答正文未发现 `search_agri_resources`、`正在调用`、`已调用` 等内部技术泄漏。
- `done` 事件含 `thread_id`、`message`、`tool_calls`，资源事件使用结构化 items。

### 第五轮：前端真实渲染、路由与响应式布局

- Chrome 自动化桌面验证：输入框、新建会话、知识库状态均存在；发送小麦锈病问题后出现“回答完成”、农业决策卡、知识上下文和五段标题。
- 资源请求出现“相关图片与资料”“官方文档”卡，页面图片节点正常，工具内部名称未泄漏。
- 移动端 390x844 验证 `/`、`/crop-diagnosis`、`/farming-calendar`、`/policy`、`/jxau-news/1`：全部 200，无水平溢出。
- `/api/rag-test-prompts`：200，提示词条目不少于 20 条。
- Playwright 包可加载，但本机未缓存其自带 Chromium；验收使用已安装 Chrome 可执行文件完成真实 DOM 交互。

## 已修复缺陷

1. 赣南脐橙采后问题被领域 guard 错误归类为 ambiguous。
2. 江农重点领域无专项文档，家猪/鄱阳湖/赣南脐橙查询会落到通用低相关文档。
3. 本地中文短查询的向量距离排序不稳定，增加 lexical rerank 和专题知识包初始化补偿。

## 发布前剩余事项

1. 接入并验证江西气象、农情、土壤等真实 API；当前工具层不能宣称已接入第三方 MCP。
2. 为 19 个文档补齐来源 URL、发布日期、版本和授权字段，前端展示证据新鲜度。
3. 在 CI 中安装固定版本浏览器，补充断言图片 HTTP 状态、SSE 中断恢复和多会话并发。
4. 对农药、肥料、疫病和动物健康问题增加人工专家抽样复核；图片识别不得作为自动确诊或自动处方。
