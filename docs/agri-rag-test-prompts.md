# CropWise 农业 RAG 测试提示词

这些问题用于验证检索命中、答案引用、边界处理和工具调用。每条都应检查：是否命中相关文档、是否给出适用条件、是否避免编造剂量、是否提示当地农技部门复核。

## 作物种植

1. 水稻播种前需要做哪些种子处理？
2. 水稻插秧时每穴适合留几株苗，行距和株距怎么安排？
3. 水稻分蘖期应该保持什么水层？
4. 水稻抽穗期和成熟期的灌排管理有什么不同？
5. 小麦适合什么时候播种，播种深度和每亩播种量是多少？
6. 小麦返青期和拔节期分别应该关注什么农事？
7. 玉米发芽最低温度是多少，适合多深播种？
8. 玉米亩保苗数量和大喇叭口期管理怎么做？

12. 小麦锈病发病初期可以采取哪些农业和药剂措施？
13. 玉米心叶被蛀，如何判断是否是玉米螟？
14. 玉米螟的生物防治和心叶期防治怎么安排？
15. 小麦和玉米同时发生蚜虫时，如何做综合治理？
16. 只凭一张模糊叶片照片能否确定病害和推荐农药？

## RAG 边界与来源

31. 知识库没有收录的油菜病害应该如何回答，哪些内容不能编造？
32. 请列出本次回答实际参考的知识库条目和匹配依据。

## 记忆相关性与主动提取

## 多轮对话与冲突整理

53. 第一轮说处于分蘖期，下一轮说其实已经抽穗，回答应如何解释状态更新？

56. 记忆冲突时，如何展示新值、旧值、时间和来源，而不是静默覆盖？
57. 删除一条用户记忆后，新会话是否还能通过相似度召回它？
58. 未确认的用户偏好能否进入默认提示词？请说明验证门槛。
