# AgriQA 前端开发方案与交付标准

## 1. Experience Brief

- 项目类型：农业知识 RAG + 问答 Agent 工作台。
- 主要用户：农业科研人员、农技人员与需要快速获得现场建议的农场管理者。
- 核心动作：在当前作物、生育期和区域上下文下提出问题，并快速判断答案是否有可核验依据。
- 可信证据：真实问答接口返回的回答、检索动作、来源列表和证据等级；来源可点击查看摘要与原始链接。
- 页面角色：生产辅助决策工作流，不是营销落地页。
- 艺术方向：Precision system。以农业知识操作系统为骨架，用低饱和土壤绿、纸张白和少量琥珀/蓝色状态色建立可靠、克制、适合长时间工作的界面。
- 交互预算：克制状态动效。仅保留加载反馈、来源弹层、移动端农情抽屉和按钮状态变化；支持 `prefers-reduced-motion`。

## 2. 页面结构与职责

1. 左侧导航：工作台、知识检索、作物档案、病虫害诊断、农情图谱和最近会话，建立工作空间心智模型。
2. 中央对话区：空状态先给出三个农业问题入口；对话态显示用户问题、Markdown 答案、检索动作、证据保护状态和来源入口。
3. 输入区：发送农业问题，并把当前选中作物、生育期与区域通过 `scenario_context` 传给既有后端接口。
4. 右侧农情区：江西赣州当前区域、关注作物、气象、风险提醒和回答依据；移动端改为侧滑抽屉。
5. 来源详情：展示发布机构、证据等级、相关度、片段和原始链接，避免只展示不可验证的来源标签。
6. 会话记录：提供当前会话与最近会话的可见弹层反馈；清空会话调用既有删除接口。

## 3. 视觉系统

- 字体：中文系统字体保证本地可用性；产品标题与大标题使用 Georgia 衬线字体，形成农业知识与操作工具的区分；技术状态使用等宽字体。
- 基础色：`#f4f4ef` 画布、`#fbfbf8` 内容面、`#202a22` 主文字、`#778078` 辅助文字、`#dfe3da` 分隔线。
- 语义色：`#326b45` 主行动与可信状态；`#b9782f` 风险与关注；`#4e7295` 气象与信息状态。
- 尺寸：桌面侧栏 236px、农情栏 312px、顶部栏 68px；输入发送按钮 33px；所有结构尺寸稳定，避免文本加载造成布局跳动。
- 组件原则：分组面板使用分隔线和留白，重复信息使用轻量边界；不使用装饰性渐变、玻璃拟态、漂浮光球或无任务意义的卡片堆叠。

## 4. 数据与接口映射

- 请求：`POST /api/chat`，发送 `message`、`thread_id`、`answer_mode`、`scenario_context`。
- 回答：消费 `message`、`sources`、`tool_calls`、`completion_status`。
- 清空：`DELETE /api/history/:thread_id`。
- `sources` 由回答内的来源按钮和右侧回答依据共同消费；点击后统一打开来源详情。
- 没有来源时显示明确空状态；`error` 与 `guarded` 状态分别显示连接失败和证据保护提示。

## 5. 响应式与无障碍验收

- `1440px`：三栏工作台完整显示，无横向滚动。
- `800px` 以下：隐藏桌面侧栏，保留移动顶部栏；农情栏变为右侧抽屉，提供打开/关闭按钮。
- `390px`：标题、问题入口、输入区和免责声明不重叠，页面无横向溢出。
- 所有按钮使用原生 `button`，图标按钮有 `aria-label`；输入框有可读标签；弹层使用 `role=dialog` 与 `aria-modal`。
- 所有控件具备 hover、focus-visible、disabled、loading 状态；动画在减少动效设置下被压缩。

## 7. 后续工程化边界

本次交付聚焦前端工作台与既有接口接入。地图真实图层、实时天气服务、病害图片识别、持久化会话列表和完整导航页面应作为后续模块接入，不在首轮以静态数据冒充已上线能力。

## 8. 第二轮 James McDonald 风格优化

本轮采用可迁移的设计方法，不复制个人作品或品牌资产：

- 引入 Raycast 式命令入口，顶部支持 `Ctrl/Cmd + K`，可进入提问、农情上下文和会话记录。
- 增加“检索路径”上下文条，把作物、生育期、区域和当前就绪状态放到提问之前，明确 Agent 的工作边界。
- 将命令面板设计成紧凑的列表交互：图标几何统一、快捷键有明确位置、hover/focus/关闭状态完整。
- 将加载状态从单一“正在思考”升级为农业知识检索阶段反馈，展示区域规范、作物档案和病虫害依据三个工作对象。
- 调整标题与顶部结构的垂直占比，提升工作区信息密度，同时保留农业领域需要的安静留白。

新增验收项：

- `Ctrl/Cmd + K` 可打开命令面板，`Escape` 可关闭。
- 命令面板中的“查看当前农情”可打开上下文面板。
- `1440px` 和 `390px` 视口均无横向溢出；移动端检索路径可读且不挤压输入区。

## 9. 真实联调与品牌归属

本轮已从“静态原型交互”推进到真实前后端联调：

- 前端改为消费 `POST /api/chat/stream`，解析 `status`、`trace`、`tool`、`sources`、`delta`、`guard`、`error` 和 `done` 事件。
- Agent 工作记录会把真实的路由、知识库检索、工具调用和安全边界显示在对话工作区中。
- `/api/health` 决定“在线/离线”状态，不再硬编码在线。
- `/api/news` 显示江西农业大学官方动态；`/api/threads` 和 `/api/history/:thread_id` 支持读取真实会话列表与历史内容。
- `/api/chat/stream`、`/api/threads` 和 `/api/news` 已加入 Next.js rewrites。

品牌身份恢复为：

- 产品名：`CropWise`。
- 归属：`江西农业大学`。
- 产品身份：`官方农业智能问答助手`。
- 知识特色：江西双季稻、赣南脐橙、鄱阳湖生态、农业资源环境、现代农业装备与植保等江农专题知识域。

因此，江西农业大学不是被当作装饰性 Logo 使用，而是同时出现在产品品牌、服务状态、官方动态和回答知识来源的信任链中。

联调验收记录：

- `GET /health`：`healthy`，知识库返回 45 份文档，LLM 连接状态为 true。
- `GET /news`：成功返回江西农业大学官方动态。
- `GET /threads?limit=3`：成功返回真实历史会话。
- `POST /chat/stream` 农业问题：返回 `mode / status / tool / trace / sources / delta / done` 事件，实测 510 个增量片段、3 条来源，完成状态为 `complete`。
- 浏览器联调：CropWise 品牌、江农动态、在线状态、SSE Agent 工作记录和来源按钮均已在页面展示。

## 10. 本轮浏览器反馈闭环

- 江西农业大学品牌：新增官网公开的校徽与校名标识资产，来源为 `https://www.jxau.edu.cn/images/favicon.png` 与 `https://www.jxau.edu.cn/images/logo.png`，分别用于清晰校徽图形和官方校名标识栏；校徽采用浅色独立容器，校名标识使用短版江农绿色条，避免官方红色大面积干扰农业工作台的绿色视觉系统；桌面侧栏与移动顶栏均保留江农识别。
- 品牌入口：移除卡片顶部重复校徽，仅保留一个官方校名标识；整个江西农业大学卡片作为官网入口，点击后打开 `https://www.jxau.edu.cn`。
- 最近会话：侧栏不再渲染完整 `last_message`，仅显示会话标题、消息数量和更新时间，避免长回答撑高导航并泄露回答正文到摘要位。
- 固定输入区：应用根节点与工作区采用视口高度约束，中央消息列表独立滚动，输入区固定在对话底部；移动端同步处理安全区和 `390px` 宽度。
- Agent 过程：回答正文和可核验来源保持默认可见，检索路由、工具调用与状态事件归入“Agent 工作记录”；请求处理中自动展开，完成后自动折叠，用户可通过键盘可达的切换按钮查看。
- 回答层级：回答前置结论直接显示；从编号分析段开始的现场摘要、病害判断、管理建议、风险边界和复查节点统一收纳进 `details.answer-details`，默认关闭，点击“详细分析与管理建议”后可展开，再次点击可收起，不把长篇分析直接堆在结论后。
- 面板控制：桌面顶部提供主导航和当前农情的隐藏/恢复按钮；隐藏后中央工作区扩展，恢复按钮保持可达。移动端主导航使用抽屉与遮罩，当前农情使用右侧抽屉，并同时支持关闭按钮和 `Escape` 关闭。

本轮验收标准：校徽图片可加载且具备替代文本；最近会话摘要不包含回答正文；江农卡片链接至 `https://www.jxau.edu.cn` 并以新窗口打开；桌面与移动端输入区底部坐标稳定；回答详细分析默认折叠且可展开/收起；左右面板可隐藏/恢复；移动端导航遮罩与农情抽屉可关闭；页面无横向溢出，构建和真实 SSE 联调通过。

浏览器运行态记录：桌面 `1440x900` 验证通过，三栏工作台可见、输入区底部为视口底部且无横向溢出；加载历史水稻病害回答后，`details.answer-details` 的 `open` 属性初始为 `false`，展开后可见编号 `0-5` 详细内容，再次点击恢复折叠。桌面主导航与农情面板隐藏后均出现对应恢复按钮，恢复后面板重新可见。移动 `390x844` 验证通过，导航抽屉可由打开按钮、抽屉关闭按钮和抽屉外遮罩关闭，农情抽屉可打开/关闭，输入区底部保持 `844px`，页面 `scrollWidth` 不超过视口宽度。

## 11. 前后端接口对齐与真实功能验收

- 真实问答：前端 `POST /api/chat/stream` 对应后端 `POST /chat/stream`，消费 `status`、`trace`、`tool`、`sources`、`delta`、`guard`、`answer-replace`、`done` 和 `error` 事件；结构化作物、生育期、区域字段随 `scenario_context` 发送。
- 真实会话：`GET /api/threads`、`GET /api/history/:thread_id` 和 `DELETE /api/history/:thread_id` 已分别用于历史列表、会话恢复和清空会话；会话记录弹层不再使用固定示例。
- 真实知识工作区：知识检索与作物档案调用 `/api/knowledge-base/search`，返回混合检索片段和相关度；病虫害诊断进入工作台真实 Agent 输入流；农情图谱调用 `/api/knowledge-graph/status` 与 `/api/knowledge-graph/search`，Neo4j 不可用时显示真实不可用状态，不渲染假节点。
- 真实农情上下文：区域选择调用 `/api/weather`，后端适配 Open-Meteo 公共预报；温度、最低温、降水和风速由接口返回。上游不可用时显示“天气服务暂不可用”和实际风险边界，不以静态数字兜底。
- 真实系统状态：工作台设置调用 `/api/system/info` 展示实际检索栈、知识图谱类型、来源统计和知识包数量；帮助面板明确真实接口边界。新增 Next rewrites 覆盖 weather、knowledge-base、knowledge-graph、system-info 和 evidence-sources。

本轮运行态证据：知识库检索“水稻 病害”返回 3 条真实结果；作物档案自动填充“水稻 分蘖期 管理 病虫害 施肥”并返回 3 条结果；区域切换到南昌后天气接口返回 34°C、降水 2.1 mm、风速 20 km/h；历史弹层显示后端返回的 8 条会话；系统设置返回 version `2.0.0` 及 retrieval/config 数据；图谱检索显示 Neo4j 连接状态 `error`，没有伪造图谱结果。
