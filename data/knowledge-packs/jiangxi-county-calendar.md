# 江西县域主要作物农时日历

## 一、江西省气候与种植制度概述

江西省属亚热带季风湿润气候，年均温16.3-19.5℃，年降水量1341-1943mm，无霜期241-307天。全省以**双季稻**种植制度为主，赣北及山区兼有单季稻和油菜种植。

## 二、油菜农时日历（赣中赣北为主）

| 时段 | 关键农事 | 备注 |
|------|---------|------|
| **9月中旬-10月上旬** | 油菜播种（直播/育苗） | 适宜地温20-25℃，抢墒播种 |
| **10月中下旬** | 育苗移栽 | 苗龄30-35天，5-6叶移栽 |
| **11月上中旬** | 查苗补缺、施苗肥 | 确保冬前壮苗 |
| **12月中下旬** | 施腊肥、培土防冻 | 结合清沟排渍 |
| **2月中下旬** | 蕾薹肥、清沟排渍 | 气温回升后及时追肥 |
| **3月中旬-4月上旬** | 初花期菌核病防治 | 关键防控窗口 |
| **4月下旬-5月中旬** | 终花后管理 | 打除老叶，防倒伏 |
| **5月中下旬** | 适时收获 | 全株2/3角果枇杷色时收割 |

> 来源：《江西省油菜生产技术指导意见》（江西省农业农村厅，2024）

## 三、早稻农时日历

| 时段 | 关键农事 | 备注 |
|------|---------|------|
| **3月上中旬** | 种子处理（浸种催芽） | 温水浸种，破胸露白播种 |
| **3月中下旬** | 播种育秧 | 旱育秧或湿润育秧，秧田播种量40-50 kg/亩 |
| **4月中下旬** | 整田、施基肥 | 翻耕后泡田耙平，基肥面施+深施 |
| **4月下旬-5月上旬** | 机插秧/手工移栽 | 秧龄25-30天，叶龄3.5-4.5叶 |
| **5月中下旬** | 返青分蘖期管理 | 浅水促蘖，施分蘖肥（尿素5-7 kg/亩） |
| **6月上中旬** | 晒田控苗 | 茎蘖数达到目标穗数80%时及时晒田 |
| **6月下旬-7月上旬** | 穗肥、病虫防治 | 施保花肥，防治稻纵卷叶螟、稻飞虱 |

> 来源：全国农技推广中心《长江中下游水稻绿色生产技术》，2024

## 四、晚稻农时日历

| 时段 | 关键农事 | 备注 |
|------|---------|------|
| **6月上中旬** | 晚稻种子处理、播种**（迟熟品种）** | 早熟品种6月下旬播种 |
| **6月中下旬** | 早稻收割前15-20天播种**（早熟品种）** | 采用盘育秧/工厂化育秧 |
| **7月上中旬** | 早稻收割、秸秆还田 | 机收后秸秆粉碎翻压 |
| **7月中旬** | 晚稻移栽（"双抢"关键期） | 早稻收后及时栽插，秧龄不超过20天 |
| **7月下旬-8月上旬** | 返青分蘖期 | 浅水层管理，施分蘖肥 |
| **8月中下旬** | 晒田控苗 | 适时适度晒田 |
| **9月上中旬** | 穗肥、水分管理 | 保持浅水层，防治"两迁"害虫 |
| **10月中下旬** | 晚稻成熟收获 | 腊熟期排水，适时收割 |

## 五、区域差异说明

- **赣南（赣州）**：无霜期长（290-310天），早稻播种可提前至3月上旬，晚稻收获可延至11月上旬
- **赣北（九江）**：无霜期较短（240-260天），晚稻应选择早中熟品种，确保9月底前安全齐穗
- **山区（井冈山、武夷山区）**：海拔每升高100m，播种期推迟3-5天
