# CropWise 品牌资产来源

- `jxau-official-logo.png`：江西农业大学官网公开的 `https://www.jxau.edu.cn/images/logo.png`，用于左侧学校信息区。
- `jxau-favicon.png`：江西农业大学官网公开的 `https://www.jxau.edu.cn/images/favicon.png`，用于校徽图标和浏览器图标。
- `jxau-official-emblem.svg`：完整校徽 SVG，来源为 [维基百科文件页](https://zh.wikipedia.org/wiki/File:Jiangxi_Agricultural_University_Emblem.svg)，该文件说明其提取自江西农业大学官网学校标识页提供的校徽矢量源 [xh.zip](https://www.jxau.edu.cn/xh.zip)。文件页标注为商标合理使用，不应表述为开源许可。

项目优先使用真实校徽 SVG，而不是自制复刻图。官网公开的组合字标和 favicon 仍保留在本地；如校方提供正式授权或开源 SVG，可直接替换 `jxau-official-emblem.svg`，组件路径保持不变。
