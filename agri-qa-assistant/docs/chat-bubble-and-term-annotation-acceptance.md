# CropWise 对话气泡与专业词条交付标准

日期：2026-08-09

## 交付结论

本次完成两项可交付能力：

1. 用户消息改为浅绿色背景、深绿色文字和明确边框，避免品牌红底与 Markdown 深色文字冲突。
2. 增加默认关闭的“专业词条”开关。开启后，回答中的可核验农业术语显示信息角标；点击、悬浮或键盘聚焦时按需拉取权威来源介绍。接口无匹配时不显示虚假词条。

## 专业词条行为标准

- 默认关闭，不主动改变现有回答内容。
- 开启后仅标注内置白名单术语：稻飞虱、条锈病、分蘖期、双季稻、赣南脐橙、红壤、鄱阳湖、植保无人机。
- 每个术语必须包含：定义摘要、来源机构、来源名称、HTTPS 链接。
- 角标使用按钮语义，具备 `aria-label`、`aria-expanded`，支持鼠标 hover、键盘 focus、Enter 点击。
- 首次打开才请求 `/api/agri-terms/lookup`，避免默认请求和重复请求。
- 后端返回 404 或网络失败时，只保留原术语，不显示空卡片、不生成来源。
- 术语摘要仅作知识解释，不用于病害自动确诊、农药自动处方或替代现场专家判断。

## 自动化验收

### API

- `GET /agri-terms/lookup?term=稻飞虱`：200，返回摘要与官方来源。
- 未知术语：404，不伪造内容。
- Next rewrite `/api/agri-terms/lookup`：转发稳定。

### 前端真实交互

- 桌面端默认可见“专业词条 关”，回答完成后角标数量为 0。
- 开启后角标出现，`aria-label` 形如“查看分蘖期专业词条”。
- 点击角标后 `aria-expanded=true`，弹层节点出现；弹层包含摘要和来源链接。
- 390px 移动端不出现水平溢出，角标仍可键盘访问。
