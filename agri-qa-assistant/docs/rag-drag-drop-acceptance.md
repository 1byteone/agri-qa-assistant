# CropWise 文档拖拽上传验收标准

## 功能契约

- 支持将单个 TXT、Markdown、CSV、HTML、JSON、DOCX 或 PDF 文件拖入对话页。
- 拖入时显示“松开以解析农业文档”遮罩；松开后自动复用文档解析和农业领域预检。
- 页面不会被浏览器默认行为导航到本地文件。
- 单次多文件拖入只处理第一个文件并明确提示；不支持格式和超过 15MB 文件在前端先拒绝。
- 农业文档仍需点击“确认加入知识库”才会向量化入库。
- 移动端没有拖拽事件时，回形针按钮保持可用。

## 验收门槛

| 级别 | 标准 |
| --- | --- |
| P0 | 拖入农业文档能够触发 analyze API，页面无文件导航，既有点击上传不回归 |
| P1 | 拖拽遮罩可见、可退出，重复 enter/leave 不闪烁；只处理一个文件 |
| P1 | 格式、大小、空文件和后端解析失败均有用户可读反馈 |
| P1 | 未确认不入库；入库成功、重复入库和拒绝状态清晰可见 |
| P2 | 键盘、屏幕阅读器状态可感知；390px 移动端无水平溢出 |
