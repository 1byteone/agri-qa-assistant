# CropWise 回答模式契约

## 模式定义

- `professional`（默认）：完整农业决策卡，包含现场摘要、优先判断、现在做什么、风险边界、复查节点，并保留知识库依据和工具结果。
- `brief`：先结论，再给最多 3 条建议和 1 条风险提醒，服务端限制在约 600 字符以内，不渲染五段式决策卡。

## 请求

```json
{
  "message": "水稻稻飞虱怎么防治？",
  "thread_id": "thread_demo",
  "answer_mode": "brief"
}
```

未传 `answer_mode` 时兼容旧客户端并使用 `professional`。非法值由 Pydantic 返回 422，不静默切换。

## 流式事件

允许的客户端事件包括：

- `mode`：后端确认实际模式；
- `delta`：模型增量文本；
- `answer-replace`：简要模式的服务端长度兜底结果；
- `done.answer_mode`：最终持久化回答采用的模式。

两种模式都必须经过农业领域守卫、知识库检索和工具安全边界；简要模式只改变表达长度，不改变允许回答的领域和风险提示。
